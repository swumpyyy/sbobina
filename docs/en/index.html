How it works

Six steps. Nothing made up.

Each step removes one kind of mistake. Anything the teacher did not say only goes into Integration boxes, and doubtful passages stay marked [uncertain].

Time

On an M-chip Mac a one-hour lecture takes half an hour to an hour. You see live what it is doing, with a time estimate, and you can stop and resume.

Queue

Drop in several recordings at once: they are processed one at a time, with a notification when each lecture is done.

macOS.dmg

Sbobina for Mac

A Mac with an Apple chip (M1 or later), macOS 12 or newer. Open the .dmg and drag Sbobina into Applications.

Download for Mac
Windows.zip

Sbobina for Windows

Windows 10 or 11, an NVIDIA graphics card recommended. Extract the zip and double-click Installa Sbobina.bat. Same version as the Mac, with the same features.

Download for Windows

First launch on a Mac: right-click the app → Open, because the app is not signed by Apple yet. Every version is on the GitHub Releases page.

From source

Maczsh
# Python 3.10+ and ffmpeg, then:
git clone https://github.com/swumpyyy/sbobina.git
cd sbobina
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[locale,app]"
./scripts/crea_app_macos.sh

Creates Sbobina.app. With --dmg it builds a standalone app to share with classmates.

WindowsPowerShell
git clone https://github.com/swumpyyy/sbobina.git
cd sbobina
powershell -ExecutionPolicy Bypass `
  -File scripts\installa_windows.ps1

Installs Python 3.12, the packages and ffmpeg, and puts Sbobina on the Desktop. Needs a recent NVIDIA driver.

Recording tipsaccuracy starts here

Sit in the front rows or put the phone near the desk, microphone towards the teacher. Airplane mode while recording. One file per lecture. Add the slides: it is the most effective way to get terms, formulas and names right.
