Come funziona

Sei passaggi. Niente di inventato.

Ogni passaggio toglie un tipo di errore. Ciò che il docente non ha detto finisce solo nei riquadri Integrazione, i punti dubbi restano segnati [incerto].

Tempi

Su un Mac con chip M una lezione di un'ora richiede da mezz'ora a un'ora. Vedi in diretta cosa sta facendo, con una stima del tempo, e puoi fermare e riprendere.

Coda

Carica più registrazioni insieme: vengono elaborate una alla volta e a fine lezione arriva una notifica.

Dal codice sorgente

Maczsh
# Python 3.10+ e ffmpeg, poi:
git clone https://github.com/swumpyyy/sbobina.git
cd sbobina
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[locale,app]"
./scripts/crea_app_macos.sh

Crea Sbobina.app. Con --dmg crea un'app autonoma da dare ai compagni di corso.

WindowsPowerShell
git clone https://github.com/swumpyyy/sbobina.git
cd sbobina
powershell -ExecutionPolicy Bypass `
  -File scripts\installa_windows.ps1

Installa Python 3.12, i pacchetti e ffmpeg e mette Sbobina sul Desktop. Serve un driver NVIDIA recente.
